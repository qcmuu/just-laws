# 變態鬼男下手同居人國小女兒！藉口犒賞工作累 強逼打X槍捧X液

 記者 林意筑 台中報導 

 2026/08/09 13:52:00 

台中市一名男子阿國，自2010年起與同居女友及其女兒花花同住，竟於2014年至2017年間多次對當時僅11歲的花花伸出魔爪，以「犒賞」為由強制猥褻並逼迫打手槍，惡劣行徑直到花花上大學接受心理諮商時才揭發。台中地院一審依強制猥褻等罪，判處阿國合併應執行刑4年4個月。阿國不服上訴，台中高分院審理後，雖認定部分細節存在微小出入而撤銷改判，但仍維持原判決刑度，全案仍可上訴。此案凸顯保護未成年人免受性侵害的重要性，提醒大眾若遇相關事件應勇於求助，守護兒少權益。

國小女童遭母親同居男友多次猥褻。（示意圖／PIXABAY）

台中市一名男子阿國（化名）自2010年起與同居女友及其幼女花花（化名）同住在台中南屯區租屋處，未料阿國多次以「工作很辛苦」、「犒賞我一下」為由對年僅11歲的花花伸出魔爪，儘管期間花花強烈拒絕，但阿國仍強逼花花替他「打Ｘ槍」，更要求花花捧著Ｘ液，行為極為惡劣。不過多年來花花默默承受創傷，直至念大學進行心理諮商輔導時，才在心理師鼓勵下揭發這段長達3年的噩夢。

據了解，2014年至2017年時，花花年僅11歲至13歲、就讀國小五年級至國中一年級。未料阿國在這3、4年間，多次以「工作很辛苦」、「犒賞我一下」為由，強行猥褻花花，更二度在浴室內逼迫花花替他「打Ｘ槍」，甚至要花花親手捧著Ｘ液，並謊稱「放久了會變透明」，極為惡劣。

多年來花花默默承受創傷，直至今年前往大學就讀並進行心理諮商輔導時，才在心理師鼓勵下揭發這段長達3年的噩夢。全案經檢警偵辦，依《家庭暴力防治法》妨害性自主罪嫌及《刑法》強制猥褻等罪提起公訴。台中地院審理期間，阿國矢口否認犯行，但法官審酌花花歷次證述前後高度一致，並輔以精神科就診紀錄與親友證詞，明確證實花花因長期遭猥褻而承受巨大身心創傷，認定男子犯行明確，一審時依強制猥褻罪判處3年6月，另2次猥褻罪各判10月，合併應執行有期徒刑4年4個月。

對此判決阿國不服判決提出上訴，於台中高分院主張花花僅有單一指訴且證述前後不一，請求撤銷改判。台中高分院審理後指出，一審認定男子「強行脫去外褲、內褲」之細節，與花花證述「不記得是他幫我脫還是我自己脫」微有出入，因此撤銷該部分原判，但仍維持3年6月重判；其餘兩罪上訴駁回，最終合併應執行刑期依然維持4年4個月。全案目前仍得上訴。
